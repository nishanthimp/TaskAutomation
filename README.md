# CodeAlpha Email Extraction Automation

## Description
This project is a simple Python automation program that extracts email addresses from a text file.

## Features
- Reads text from a file
- Finds email addresses automatically
- Extracts valid email addresses using Python
- Saves the extracted emails into a separate file

## Technologies Used
- Python
- Regular Expressions
- File Handling

## Input
The program reads email and text data from `emails.txt`.

## Output
The extracted email addresses are saved in `extracted_emails.txt`.

## How to Run
Open the terminal in the project folder and run:

python extract_emails.py
